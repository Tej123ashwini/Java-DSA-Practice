### 3. Student Management System 

A Java console-based mini-project designed to manage student information using Object-Oriented Programming and Java collections.

Technologies and concepts used:
- Java
- OOP concepts
- ArrayList
- Constructors
- Encapsulation
- Loops and conditional statements
- Methods and exception-free input validation

Functionalities:

| Functionality         | Description                                                                |

| Add Student           | Adds a new student with details such as USN, name, age, course, and marks. |
| Display Students      | Displays the details of all registered students.                           |
| Search Student        | Searches for a student using their USN.                                    |
| Update Student        | Modifies the details of an existing student.                               |
| Delete Student        | Removes a student record using their USN.                                  |
| Count Students        | Displays the total number of registered students.                          |
| Average Marks         | Calculates the average marks of students.                                  |
| Highest Marks         | Identifies the student with the highest marks.                             |

Implementation:

Student records are stored using an `ArrayList<Student>`, allowing dynamic storage without specifying a fixed array size.

Each student is represented as an object of the `Student` class. The application uses methods to perform individual operations, making the code modular and easier to maintain.

### 4. Expense Tracker 💰

A Java console-based mini-project developed to record, manage, and analyze personal expenses.

The application allows users to maintain expense records and calculate spending based on individual expenses and categories.

Technologies and concepts used:
- Java
- Object-Oriented Programming
- LinkedList
- HashMap
- Constructors
- Iteration and conditional statements
- Input validation
- Formatted console output

Functionalities:

| Functionality        | Description                                                               |

| Add Expense          | Records a new expense with an ID, description, amount, and category.      |
| View Expenses        | Displays all recorded expenses in a structured format.                    |
| Delete Expense       | Deletes an expense using its unique ID.                                   |
| Search Expense       | Finds and displays an expense using its ID.                               |
| Update Expense       | Modifies the description, amount, and category of an existing expense.    |
| Total Expenses       | Calculates the total number of expenses and the overall amount spent.     |
| Category Expenses    | Calculates and displays the total spending for a selected category.       |

Implementation:

The application uses `LinkedList<Expense>' to store expense objects dynamically.

Each expense is represented by an object of the `Expense` class, containing an ID, description, amount, and category.

`HashMap<String, Double>` is used to group expenses by category and calculate the total amount spent in each category.

The application also includes input validation to prevent invalid IDs, empty descriptions, and zero or negative expense amounts.
